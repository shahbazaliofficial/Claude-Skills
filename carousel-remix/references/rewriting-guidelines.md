# Rewriting Guidelines

## What "noticeably better" means

Improve the actual craft of each slide, not just swap synonyms:

- **Hook slide**: sharper, more specific, more scroll-stopping than the original — a vague hook ("5 tips for better writing") should become something with more edge or specificity ("The writing habit that made my posts 3x more readable"), if the topic supports it. Don't invent fake specifics (fabricated numbers/stats) — sharpen based on what's actually true of the content, not by making up proof points.
- **Point slides**: clearer framing, tighter wording, a stronger example if one is missing. If the original point is vague or generic, sharpen it into something more concrete and useful.
- **Flow between slides**: each slide should pull the reader to the next — check that the rewritten sequence reads as a connected narrative, not N independent slides that happen to be in order.
- **Closing/CTA**: make the ask or takeaway clear and specific rather than generic ("follow for more" → something tied to the actual value just delivered, if that fits the user's voice).

## Staying structurally faithful, content-wise original

- Keep the same number of slides and the same general role for each slide position (if slide 3 was a "point" slide in the source, slide 3 in the rewrite should also be a point slide) — this is what "similar way" means.
- The actual claims, examples, and phrasing should be freshly written, not adapted-with-synonyms from the source. A useful test: if you laid the original and the rewrite side by side, someone should not be able to tell the rewrite was "based on" the original from the wording — only the topic and structural shape should be recognizable.
- If the source makes a specific, checkable claim (a statistic, a named study, a specific number), don't invent a different number to seem original — either keep the same factual claim (expressed in new wording) or, if unsure of its accuracy, frame it more generally rather than fabricating a replacement stat.

## Tone and voice

- Default to a confident, clear, professional tone appropriate for LinkedIn/Instagram thought-leadership content, unless the user has an established voice/tone preference — ask if it's unclear and it matters (e.g., very casual/meme-heavy source vs. polished corporate source might call for different rewrite tones).
- Match tone to platform norms loosely: LinkedIn carousels often skew slightly more professional/insight-driven even when casual; Instagram carousels have more range (educational, meme-adjacent, aesthetic-led) — don't force a LinkedIn tone onto an Instagram-native piece or vice versa unless the user wants that.

## Sharing the rewrite before finalizing design

Since redoing text after slides are designed is more work than iterating on the copy itself, it's worth surfacing the rewritten copy (even briefly) before or alongside the first design pass — especially for longer carousels (8+ slides) or when the topic/tone is at all ambiguous.
