# Creative & Testing Playbook

## Detecting creative fatigue

Look for the combination, not any single signal alone:
- Frequency rising on a given ad/ad set
- CTR declining over the same period
- CPM rising over the same period (auction is working harder to get the same attention)

Any one of these alone can have other explanations (seasonality, audience changes) — the combination, sustained over a meaningful period (not a single noisy day), is the real fatigue signal. Flag specific ads/ad sets showing this pattern as refresh candidates, not the whole account by default.

## Testing structure

A healthy testing cadence usually separates what's being tested so results are attributable:
- **Creative testing** — new ad variations (different hooks, formats, angles) run against a stable audience/budget so performance differences can be attributed to the creative itself.
- **Audience testing** — new audience segments tested with stable, proven creative, so differences are attributable to targeting.
- **Avoid testing both at once** in the same ad set/experiment when the goal is to learn something specific — if creative and audience change together, a result can't be cleanly attributed to either.

If the account has no visible testing structure (same 1-2 ads running for a long time, no new variations introduced), flag that as a gap on its own — an account that never tests plateaus even if current performance looks fine.

## What to recommend testing, based on findings

Ground testing recommendations in what the diagnostic actually found, not a generic list:
- If fatigue is detected on specific ads → recommend new creative variations for those specific placements, informed by what's known about the audience/objective (e.g., a UGC-style hook if static images are fatiguing, or a new format like Reels if only static/carousel has been tried).
- If CTR is strong but conversion rate is weak → the creative is earning clicks but the landing experience or offer isn't converting; this points toward landing page/offer testing more than ad creative testing.
- If the account has only ever run one format → recommend format diversification (e.g., adding Reels/video if only static images have run) as a testing priority, since format performance can vary a lot by platform surface.

## Format & hook variety (general guidance, apply where relevant)

- Video/Reels-native content generally has room to outperform repurposed static ads on placements like Instagram/Facebook Reels — worth testing if not already in the mix.
- Hook variety (the first 1-3 seconds of a video, or the headline/first line of a static ad) tends to matter more for scroll-stopping performance than deeper creative polish — if testing budget is limited, prioritize hook variations over full creative overhauls.
- UGC-style or founder-led content often outperforms polished brand creative for cold/prospecting audiences, though this varies by category — treat as a hypothesis to test, not a rule to state as certain for every account.
